## THE CORE STRATEGY

The portfolio has ONE version. But the language is written so:
- A Full-Stack HR sees: "builds complete products end to end"

- A Gen AI HR sees: "ships AI-powered products with LLMs"

The trick: use neutral but layered language. Lead with outcomes and systems. Let the reader project their lens onto it.

if loaded eagerly. Solved with lazy model loading — initialized on first request, 
cached in memory for subsequent calls.
